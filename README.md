# ontologia-para-atletismo
Ontologia sobre Atletismo desenvolvida no WebProtégé, abrangendo atletas, eventos, classificações e recordes. As definições foram baseadas em literatura esportiva, DBpedia e Wikidata, garantindo alinhamento com padrões de dados conectados e reutilizáveis.
