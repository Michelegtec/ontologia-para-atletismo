# ontologia-para-atletismo
Ontologia OWL desenvolvida para trabalho acadêmico, modelada no Protégé

Ontologia para Atletismo

Este repositório contém uma ontologia OWL desenvolvida para fins acadêmicos, da disciplina da Linked Data, modelada utilizando o Protégé e exportada pelo WebProtégé.
O objetivo é representar formalmente conceitos, classes e relações do domínio do atletismo, com foco no paratletismo, de forma bastante sintetizada, porém, permitindo análise, integração e raciocínio automatizado.

Objetivos da Ontologia

Representar elementos essenciais do paraatletismo (provas, atletas, modalidades etc.)

Estruturar conceitos e relações de forma lógica e consistente

Facilitar reuso e extensões por outros pesquisadores ou estudantes
